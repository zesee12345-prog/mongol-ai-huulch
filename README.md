# Монгол AI хуульч

Монгол Улсын хууль тогтоомж, шүүхийн шийдвэр дээр суурилсан, ишлэлтэй хариулт өгдөг RAG систем.

## Одоогийн шат: legalinfo.mn татагч (туршилт)

```bash
pip install -r requirements.txt
python -m pytest
python -m scraper.legalinfo 16390263044601 --out data/laws
```

Гаралт нь `data/laws/<lawId>.json` бөгөөд хуулийг бүлэг, зүйл, заалтаар хуваасан байна.

## shuukh.mn шүүхийн шийдвэр татагч

```bash
python -m scraper.shuukh --category criminal --level 1 --from 2026-11-01 --to 2026-11-22 --max-pages 2
```

* `--category`: `civil` (иргэн), `criminal` (эрүү), `administrative` (захиргаа); `--level`: 1=анхан, 2=давж заалдах, 3=хяналт.
* Гаралт: `data/decisions/<ангилал>/<шат>/<id>.json` — шүүх, шийдвэрийн төрөл, огноо, дугаар, хэргийн индекс,
  шүүгч, улсын яллагч, маргааны төрөл / зүйл хэсэг, хуулийн ишлэлүүд, хэсгүүд (тодорхойлох, үндэслэх, тогтоох)
  болон нууцалсан текст. Тасалдсан бол дахин ажиллуулахад аль хэдийн татсан шийдвэрийг алгасна.
* Том хэмжээгээр татахдаа огнооны мужаар (жишээ нь сар сараар) хувааж ажиллуулна.

### Хувийн мэдээлэл

shuukh.mn талуудын нэрийг гараар нууцалдаг ч алдаа гардаг (жишээ нь компанийн утасны дугаар үлдсэн).
Тиймээс `scraper/anonymize.py` текстийг хадгалахаас өмнө иргэдийн нэрийг `[ИРГЭН-1]` маягаар (нэг хүнд нэг
орлуулагч), регистр, утас, и-мэйл, хаяг, улсын дугаар, дансыг солино. Шүүгч, прокурор, нарийн бичгийн дарга зэрэг
албан тушаалтны нэрийг үлдээнэ. Энэ нь дүрэмд суурилсан эхний шат тул нийтэд гаргахаас өмнө NER загвар эсвэл гар
шалгалт нэмнэ. `--keep-raw` нь нууцлаагүй текстийг хадгалдаг тул зөвхөн дотоод шалгалтад ашиглана.
